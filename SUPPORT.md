# Getting Help

- **Found a bug?** Open an issue with the bug report template in
  [this repository's issues](https://github.com/certkiln/.github/issues/new/choose).
- **Have an idea?** Open an issue with the feature request template in the same
  place.
- **Security issue?** Don't open an issue. Follow the
  [security policy](https://github.com/certkiln/.github/blob/main/SECURITY.md).

Certkiln is in early development and maintained by a small team, so response
times may vary.
