# Contributing to Certkiln

Thanks for your interest in Certkiln!

## Current status

Certkiln is in **early development**. We're finalizing the project license and
contributor terms, and until that's done **we can't accept code
contributions** (pull requests).

You can still help right now:

- **Report bugs** with the bug report template in the relevant repository.
- **Suggest features**, especially real-world certificate workflows (x509,
  SSH, SCEP) you'd like Certkiln to handle, using the feature request
  template.
- **Report security issues** privately, following the
  [security policy](https://github.com/certkiln/.github/blob/main/SECURITY.md). Never open a public issue for these.

This page will be updated with development setup, coding standards, and the
pull request process once contributions open.

## Code of Conduct

Everyone taking part in this project is expected to follow our
[Code of Conduct](https://github.com/certkiln/.github/blob/main/CODE_OF_CONDUCT.md).
