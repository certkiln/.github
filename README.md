# certkiln/.github

Organization-wide defaults for [Certkiln](https://github.com/certkiln).

- `profile/README.md`: the organization profile shown at github.com/certkiln
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`: default
  community health files for every repository in the org that doesn't define its own
- `.github/ISSUE_TEMPLATE/` and `.github/pull_request_template.md`: default
  issue and pull request templates
